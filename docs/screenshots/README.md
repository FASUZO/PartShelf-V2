# 截图目录

此目录用于存放项目界面截图，用于 GitHub Pages 文档展示。

## 截图要求

- **格式**：PNG 或 JPG
- **尺寸**：建议宽度 1200px 以上
- **命名**：使用英文小写字母和连字符

## 需要的截图

请添加以下截图文件：

1. `inventory-main.png` - 库存管理主界面
2. `batch-stock-out.png` - 批量出库功能
3. `inventory-history.png` - 库存历史记录
4. `component-detail.png` - 元件详情弹窗
5. `settings.png` - 配置管理界面
6. `filter-sidebar.png` - 筛选侧栏

## 如何截图

1. 启动项目：`uvicorn app.main:app --reload`
2. 访问 http://localhost:8000
3. 使用浏览器截图工具（F12 → 设备模拟 → 截图）
4. 保存截图到此目录

## 注意事项

- 截图应展示主要功能
- 避免包含敏感信息（如密码、API密钥）
- 保持截图清晰、美观
- 截图会被 GitHub Pages 自动部署
