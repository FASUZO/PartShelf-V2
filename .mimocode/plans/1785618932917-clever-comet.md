# Plan: 移动端二维码扫描入库

## 需求
- 在移动端右下角筛选按钮上方添加二维码扫描按钮
- 扫描二维码后自动提取信息入库
- 二维码格式：`{pbn:PICK241130100025,on:SO2411309996,pc:C22452,pm:SS54,qty:10,...}`
- 提取字段：`pc` → LC Number, `pm` → Name, `qty` → Quantity

## 调研结果

### 立创商城 API
LCSC 提供官方 API（https://www.lcsc.com/docs/openapi/index.html），但需要 API Key。
- 搜索接口：通过关键词搜索零件，返回 LCSC 料号、型号、制造商等信息
- 产品详情接口：通过 LCSC 料号查询产品详情

**结论**：立创商城网站有反爬保护，无法直接抓取。需要 API Key 才能查询产品信息。

---

## 实现方案

### 1. 基础方案（无需 API Key）

只使用二维码中的信息：
- `pc` → LC Number
- `pm` → Name  
- `qty` → Quantity

如果库存中已存在该 LC Number 的零件，直接入库。
如果不存在，提示用户手动添加或打开添加表单预填信息。

### 2. 增强方案（需要 API Key，后续实现）

配置立创商城 API Key 后，可通过 LC Number 查询：
- 制造商 (Manufacturer)
- 封装 (Package)
- 描述 (Description)
- 类型 (Type)
- 参数规格

## QR 码解析逻辑

```javascript
// 二维码内容格式（注意：无引号的JSON）
{pbn:PICK241130100025,on:SO2411309996,pc:C22452,pm:SS54,qty:10,mc:null,cc:1,pdi:137099585,hp:11,wc:JS}

// 解析步骤：
// 1. 添加引号使其成为合法JSON
// 2. 解析为对象
// 3. 提取字段
const parsed = JSON.parse(qrText.replace(/(\w+):/g, '"$1":'));
const lcNumber = parsed.pc;  // LC Number
const name = parsed.pm;      // 零件名称
const quantity = parseInt(parsed.qty); // 数量
```

## 扫描流程

```
扫描二维码
  ↓
解析 JSON 提取 pc/pm/qty
  ↓
查询库存是否存在该 LC Number
  ↓
存在 → 显示零件信息，确认入库数量
不存在 → 打开添加表单，预填 Name/LC Number/Quantity
  ↓
确认入库
```
